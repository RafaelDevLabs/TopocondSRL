# Topocond

Aplicatie de prezentare pentru serviciile Topocond Cadastru, construita cu TanStack Start, React si Tailwind CSS.

## Cerinte

- Bun
- Node.js 22+

## Comenzi utile

```bash
bun install
bun dev
bun run build
bun run lint
```

## Structura proiectului

- `src/components` pentru componente UI si sectiuni
- `src/routes` pentru rutele aplicatiei
- `src/data` pentru continutul static
- `public` pentru asset-uri publice
